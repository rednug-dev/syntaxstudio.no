# Primary site: In relation

Current surface brief, 7 September 2026. The latest user request keeps the new Syntax identity, warm paper, deep brown, pale blue, DM Sans direction, premium tone and three-practice architecture. It replaces the former literal Open House structure. The brief asks for several structures inside that identity and selection of the strongest; A, **In relation**, was chosen under that delegated instruction after the ecosystem audit, current reference study and four code-led studies using real media. This is not a claim of separate user approval. See [the comparison](structural-exploration-2026-09.md), [the prototypes](structures.html) and [the direction contract](../../DESIGN.md).

Syntax is the independent creative house connecting ISO400 / Image & Design, 35mm / Film & VFX and Nyfane / Technology. It is the creative relationship between these specialists, not a fourth practice or a directory. The page should make this relationship tangible before explaining its organization.

The first viewport gives the whole, undistorted Syntax mark architectural scale, quiet navigation and a short independent-house/Oslo statement. Real work appears immediately in an asymmetric shared field: an ISO400 portrait, an overlapping campaign film poster and a smaller capture of Nyfane's actual website. Each remains recognizable and honestly attributed. Avoid three enclosing practice panels, fixed practice colors, mounted-print theater and literal doors. “Different rooms. Open doors.” may remain a secondary verbal idea; it is not the governing visual metaphor.

The signature is **Change the relationship**: a native labeled range and discrete presets recompose the same media, changing what leads while preserving the other disciplines as context. Direct input responds immediately; preset changes use a single 650ms exponential ease; reduced motion changes state instantly. The default composition and all essential information remain useful without interaction. Provide visible focus, native keyboard operation, selected state, comfortable touch areas and readable captions in every arrangement.

The sequence is identity → work composition → point of view → specialist relationships → campaign proof → wider work → founders → contact. Alternate density, silence and screening depth. DM Sans, shared edges, unequal proportions and deliberate crop establish the parent language. Work, case, studio and contact pages repeat that discipline without duplicating the hero effect. Preserve useful bilingual routes and direct Work, Practices, Studio and Contact access. Specialist detail stays chiefly with the specialist brands.

Use only real evidence: ISO400 portraits as image studies with unspecified client/year; the existing anonymized burger campaign with historical Syntax production credits; Nyfane's own website capture labeled **website study / in development**. Their juxtaposition is a studio composition, not a claimed shared commission. Never import Nyfane's fictional demo clients or invent 35mm assets, founder facts, awards or outcomes. Preserve project anonymity, original mark geometry and current verified founder mapping.

Mobile receives its own vertical composition: portrait leads, film crosses lower, digital capture sits offset. Keep the full mark and meaningful work in the opening, with controls close by. Do not miniaturize the desktop collage, force horizontal scrolling or make hover/drag necessary. Film stays poster-first and loads only on explicit play; playback respects its original ratio. Responsive image derivatives, reserved geometry and no large animation engine keep the opening light.

Validate the implemented core pages and signature controls in a bounded desktop/mobile browser pass, then an independent creative review and appropriate build, accessibility, SEO and performance checks. Use the in-app browser for visual QA; do not use external Playwright. This preserves the established workflow preference alongside the new design direction. Earlier Common Ground/Open House QA does not certify the In relation implementation, and this brief is a contract rather than a claim that checks have passed.
